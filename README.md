# 广告投放效果AB测试分析

## 📌 项目背景
这是一个基于**20,000名用户**真实AB测试数据的分析项目，模拟互联网产品/运营场景中常见的**效果评估需求**：评估广告投放对用户购买转化率的影响，并探索**最优投放策略**（频率、时段、日期）。

## 🎯 项目目标
1. 验证广告投放是否显著提升用户购买转化率
2. 分析不同广告曝光频率对转化率的影响
3. 探索不同投放时段、日期的效果差异
4. 为业务方提供**可执行的投放建议**

## 🛠️ 技术栈
- Python 3.x
- Pandas（数据处理）
- SciPy（卡方检验）
- Matplotlib（数据可视化）

## 📊 分析流程
1. **数据清洗与探索**：加载数据，查看字段分布与缺失情况
2. **整体效果评估**：计算广告组 vs 对照组转化率，进行卡方检验
3. **多维度拆解**：
   - 频率维度：按广告曝光次数（ad_count）分组分析
   - 时段维度：按用户活跃时段（peak_ad_hours）分组分析
   - 日期维度：按用户活跃日期（days_with_most_add）分组分析
4. **结论输出**：汇总最优投放策略建议

## 📈 核心结论
- **整体效果**：广告组转化率（6.66%）显著高于对照组（3.23%），提升约**106%**（p<0.05）
- **最优频率**：观看 **7次** 广告的用户转化率最高（6.20%）
- **最佳时段**：**上午9点** 投放效果最强（提升幅度416%）
- **最佳日期**：**第13-16天** 为广告效果黄金期（峰值提升561%）
